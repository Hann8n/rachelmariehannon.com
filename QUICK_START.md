# Quick Start Guide

## Edit the Site

1. Go to `https://app.pagescms.org/`
2. Sign in with GitHub
3. Open repository `rachelmariehannon.com`
4. Open **Site Content**
5. Edit fields and click **Save**

## Add or Edit Sections

1. Scroll to **Page Sections**
2. Click **+**
3. Choose a section type:
   - `text`
   - `quote`
   - `list`
   - `two-column`
   - `substack`
   - `events`
4. Fill only the fields you need
5. Save

## Events

Each event item uses:

- `starts_at` (date + time)
- `venue`
- `city`
- optional details and links

## Useful Tips

- Optional fields can be left blank.
- In `text` sections, use blank lines in `content` for new paragraphs.
- Use drag handles to reorder list items.
- Changes are saved to GitHub and appear on the live site after deployment.
