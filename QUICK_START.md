# 🚀 Quick Start Guide

## For Rachel: How to Edit Your Website

### First Time Setup (5 minutes)

1. **Go to:** https://app.pagescms.org/
2. **Click:** "Sign in with GitHub"
3. **Authorize:** Pages CMS to access your repository
4. **Select:** Your repository from the list
5. **Done!** You can now edit your site

### Editing Your Site

1. **Open:** https://app.pagescms.org/
2. **Click:** "Site Content"
3. **Edit:** Any field you want to change
4. **Click:** "Save" (top right)
5. **Wait:** 1-2 minutes for changes to appear on your site

### Adding a New Section

1. Scroll to **"Page Sections"**
2. Click the **"+"** button
3. Choose a **Section Type**:
   - **text** = Paragraphs of text
   - **quote** = A quote with attribution
   - **list** = A list of items
   - **two-column** = Side-by-side content
   - **substack** = Substack embed
4. Fill in the fields
5. Click **"Save"**

### Reordering Sections

- Drag sections up/down using the **⋮⋮** handle on the left

### Deleting Sections

- Click the **🗑️** trash icon

## 💡 Tips

- **Only fill fields you need** - Empty fields are fine
- **Changes save automatically** to GitHub
- **Mobile-friendly** - Edit from your phone
- **Visual preview** - See your content as you edit
