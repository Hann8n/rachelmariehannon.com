# Rachel Marie Hannon Website

Personal portfolio website for Rachel Marie Hannon.

## Project Structure

- `index.html` - Main page shell and content renderer.
- `admin/index.html` - Admin helper page for CMS editing.
- `content/site.json` - Structured page content source.
- `src/js/` - JavaScript modules (`feed.js`, `ui-components.js`).
- `styles.css`, `ui-*.css` - Site styling layers.
- `docs/` - Project and CMS setup documentation.

## Development

- Start local server: `npm run dev`
- Run reference checks: `npm run check`
- Build check (no compile step): `npm run build`

## Live Site

https://rachelmariehannon.com

## Deployment

- Platform: Cloudflare Pages
- Config: `wrangler.jsonc`
